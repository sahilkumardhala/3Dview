# DOM Matrix 3D/4D Visualizer Extension

A browser extension that extrudes any live webpage into a 3D layer stack with real-time mouse controls and depth spacing.

## Installation Instructions

1. Unzip `3Dview.zip` into a folder.
2. Open Chrome, Edge, or Brave and navigate to:
   - Chrome / Brave: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. Toggle on **Developer mode** in the top right.
4. Click **Load unpacked** and select the unzipped directory.
5. Click the extension icon on any live webpage to toggle the 3D spatial view.
